Détection d’anomalies

API REST & Machine Learning | Python · FastAPI · MySQL

Application intelligente de détection des transactions frauduleuses développée dans le cadre d’un stage Backend & Machine Learning chez RIF Tunisie. La solution expose une API REST capable d’analyser des transactions et d’identifier les comportements potentiellement frauduleux en temps réel.

Objectif du projet

Proposer une application web sécurisée intégrant des modèles d’apprentissage automatique non supervisés pour détecter les transactions suspectes, notifier les analystes et assurer la traçabilité des résultats.

Algorithmes de détection

Isolation Forest

Les anomalies étant rares et distinctes, les transactions isolées rapidement dans des branches courtes d’arbres aléatoires sont considérées comme suspectes.

Local Outlier Factor (LOF)

Les anomalies sont identifiées en comparant la densité locale d’une transaction à celle de ses voisins: les points situés dans des zones de faible densité sont des outliers.

Données utilisées

Le jeu de données comprend 140 000 transactions anonymisées, transformées par une Analyse en Composantes Principales (PCA) en 15 colonnes numériques. Les données représentent des transactions par carte bancaire et sont masquées pour préserver la confidentialité.

Fonctionnalités

  • Authentification sécurisée avec JWT pour les administrateurs et les analystes.
  • Soumission de transactions individuelles ou par lots.
  • Analyse automatisée avec Isolation Forest et LOF.
  • Notifications en temps réel pour valider ou rejeter les transactions suspectes.
  • Consultation de l’historique des transactions et des prédictions.
  • Stockage MySQL pour assurer la traçabilité des analyses.
  • Documentation et tests interactifs des endpoints avec Swagger.
